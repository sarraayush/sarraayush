## 💼 Featured Projects

### 🛠️ ResumePrompt — Full-Stack Version-Controlled AI Resume Platform
> **Production URL:** [resumeprompt.in](https://resumeprompt.in) | **Development Cycle:** March 2026 – May 2026

```
[ Next.js / Shadcn UI ] <---> [ FastAPI Gateway ] <---> [ Redis Queue / Celery Workers ]
                                     |
                          [ Langgraph AI Agent ] ---> [ RenderCV (Typst) Engine ]
                                     |
                              [ MongoDB Cluster ]
```

*   **Business Problem Solved:** Eliminated formatting errors and document layout shifting during generative AI content manipulation by decoupling data parsing from design schemas using structural JSON configurations.
*   **Architecture & Tech Stack:** Scalable full-stack engine running on **Python, FastAPI, Next.js, MongoDB, Celery, Redis, Typst, Git, and Shadcn UI**.
*   **Key Engineering Features:**
    *   **Interactive Monaco Editor:** Integrated a custom web editor layout providing real-time data adjustments over structured **JSON** and **YAML** schemas.
    *   **Agentic Frontend Workflows:** Wired stateful UI listeners to an autonomous backend orchestration layer built on **Langgraph** to update resume targets cleanly using Gemini AI.
    *   **State Delta Comparison:** Developed a side-by-side frontend evaluation layer allowing users to track structural mutations between different historical versions of a document.
    *   **Decoupled Multi-Agent Compiler:** Wrapped **RenderCV** inside isolated FastAPI threads to dynamically handle server-side typesetting processes concurrently.
