## 💼 Featured Projects

### 🛠️ ResumePrompt — Full-Stack Version-Controlled AI Resume Platform
> **Production URL:** [resumeprompt.in](https://resumeprompt.in) | **Development Cycle:** March 2026 – May 2026

```
[ Next.js / Shadcn UI ] <---> [ FastAPI Gateway ] <---> [ Redis Queue / Celery Workers ]
                                     |
                          [ Langgraph AI Agent ] ---> [ RenderCV (Typst) Engine ]
                                     |
                              [ MongoDB Cluster ]
```

*   **Business Problem Solved:** Eliminated manual, error-prone formatting and context loss during iterative technical resume creation by providing a multi-agent, version-controlled platform that handles real-time contextual updates natively.
*   **Architecture & Tech Stack:** High-performance asynchronous backend engineered via **Python, FastAPI, Next.js, MongoDB, Celery, Redis, Typst, and Shadcn UI**.
*   **Key Engineering Features:**
    *   **Agentic Document Editing:** Integrated **Gemini AI** with an autonomous orchestration layer built on **Langgraph** to edit, refine, and balance technical resumes dynamically.
    *   **Advanced Version Control:** Designed a robust state-comparison architecture allowing side-by-side differentiation of distinct resume versions.
    *   **Decoupled Compilation Engine:** Wrapped **RenderCV** (open-source python app) inside isolated asynchronous execution processes via FastAPI and Multi-Agent structures.
    *   **Real-time Monaco IDE Integration:** Embedded a customized Monaco Editor allowing developers to toggle between structure schemas via raw **JSON** and **YAML** payloads.
    *   **Security & Session Lifecycle:** Implemented bulletproof Token-based Session Management preventing unauthorized access cross-mutation.
